Управление музыкой

Кнопка управляет только открытым окном Яндекс Музыки через UI Automation. Фокус окна не меняется; глобальные медиаклавиши не отправляются.

Доступны отдельные действия: предыдущий трек, пауза/пуск, следующий трек, повтор, перемешивание, лайк, обложка и исполнитель. Перетащите нужные на верхние кнопки Stream Deck.

Золотая рамка — включённый повтор/перемешивание. Лайк вызывает кнопку сердца приложения; его состояние здесь не отображается. Окно плеера должно быть открыто; свёрнутое окно может не предоставлять кнопки.
